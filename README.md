# Pandrosion

**Geometric Root Calculators: A ninth-order nested-radical support and real-degree enclosures in the Pandrosion rectangle**

Ivan Besevic · V28 · 12 November 2026 · Research preprint

[Read the paper](paper/Geometric_Root_Calculators_v28.pdf) · [Evidence and source availability](EVIDENCE.md) · [Citation](CITATION.cff)

This repository accompanies the paper on positive-root constructions using the Pandrosion rectangle: classical rectangle supports, the fifth-order decentered arc, the nested-radical construction of order nine, and real-degree subdivision enclosures.

## Reproduce the available checks

```sh
python3 -m pip install -r requirements.txt
python3 verification/decentered/verify.py
python3 paper/v28/verify_v28.py
```

This runs symbolic identities, local series checks and 432 geometric evaluations (108 for each of four constructions) at 160 decimal digits. It regenerates `verification.json` and a four-method benchmark at 280 digits. These are finite numerical checks, not a reproduction of the paper's six-method comparison. `verify_v28.py` recomputes the V28 constants, identities and tables with exact rational arithmetic and high-precision evaluation.

To rebuild the manuscript, run `pdflatex main.tex` three times in `paper/v28`. The figures are in `figs.tex`, regenerated by `python3 genfigs.py` from exact coordinates.

For formal checking, install [elan](https://github.com/leanprover/elan), then run from the repository root:

```sh
lake exe cache get
lake build
python3 scripts/audit_lean.py
```

Lean and mathlib are pinned by `lean-toolchain`, `lakefile.toml` and `lake-manifest.json`. The audit checks 246 declarations (ten decentered algebraic certificates, seven subdivision theorems, 104 nested-radical theorems and 125 theorems on orders, degrees and efficiency), allowing only `propext`, `Classical.choice` and `Quot.sound`. CI builds the Lean library and runs these audits separately from the numerical verifier.

## Repository scope

Only the current manuscript and available mathematical support are maintained here. Superseded manuscripts, circuit/SPICE studies, the old interactive gallery and unrelated solver experiments remain recoverable in Git history before this cleanup. No history was rewritten.
