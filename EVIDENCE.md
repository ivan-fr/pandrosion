# Evidence and source availability

The current manuscript is [V28](paper/Geometric_Root_Calculators_v28.pdf), a revision of [V27-NR](paper/Geometric_Root_Calculators_v27.pdf); the V27 PDF was supplied by the author for the earlier cleanup. Section numbers below refer to V28. Files retained from the repository predate that manuscript; keeping them does not establish every V27 claim. The nested-radical modules and six further modules were added afterwards (see the table); some of the added statements (rational and irrational degrees, the closed form of the order-nine constant for every real degree, the efficiency comparison, negative degrees) belong to the V28 revision.

## Retained dependency boundary

`LeanMath.lean` imports the projective verification, decentered certificates and subdivision modules, and the nested-radical, order and degree modules added afterwards. Other retained Lean files are their transitive imports, including common scalar convergence results. The decentered certificate file now imports mathlib directly instead of the unrelated fixed-circle development; its declarations and proofs are unchanged.

The four nested-radical modules and their imports have since been added and build in the pinned environment. Completing V27 reproduction still requires the V27 manuscript sources and the V27 symbolic/geometric/comparison verifiers, which have not been reconstructed here. The V28 bibliography keeps two links from V27, to the interactive gallery and to the version 20 preprint, whose targets were removed from `main` by the cleanup and are only recoverable from Git history.

Not formalized: the correspondence between ruler-and-compass constructions and the scalar updates for the decentered arc and nested radicals, the trace-counting protocols, higher-order remainder terms beyond the leading constants, the classical constants of the comparison table, and the degree-four computation.

## Numerical checks

Run `python3 verification/decentered/verify.py` after installing `requirements.txt`. The unchanged verifier uses intersections and a constructed arc radius, compares its readout with independent scalar formulas, and records the exact scope in its JSON outputs. Its example uses the reciprocal state and four methods; it is not the V27 nested-radical benchmark. `python3 paper/v28/verify_v28.py` checks the V28 formulas; it is a computer-algebra and numerical check, not a proof.

## Formal checks

`lake build` compiles every retained module through the root imports. `python3 scripts/audit_lean.py` additionally prints transitive axioms for the ten decentered certificates, seven subdivision theorems, all 104 theorems of the four nested-radical modules and all 125 theorems of the six added modules, rejecting admitted proofs or nonstandard axioms. The audit establishes that these statements are proved from the standard axioms; whether each statement matches the manuscript's wording is a matter of reading the Lean statements.

## Merge configuration

The existing `main` protection requires legacy paper, analog and gallery job names. This cleanup keeps the Lean and mathematics status names, but removes jobs for deleted studies. Before merging, the repository owner must update the required-check list to the two retained jobs: `Complete Lean build and separate axiom audits` and `Symbolic and high precision geometry`. No branch protection is disabled or bypassed by this change.
